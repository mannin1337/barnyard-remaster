# Barnyard Remaster v5.5-lan.1 – LAN minigame fixes

To play over LAN, install this release on both computers using each player's own copy of Barnyard for PC. On Windows, the host runs `Barnyard_LAN_szerver.bat` and the guest runs `Barnyard_LAN_csatlakozas.bat`. Once on the farm, open the pause menu and select **LAN Minigames**. [Windows and Linux (Proton) setup guide](https://github.com/mannin1337/barnyard-remaster/blob/main/RemasterTools/Patch/INSTALL.md)

- **Mud Jumpers.** The shared arena now loads when playing as a female character. The guest sees their character prepare to jump as soon as they press the button. The gate and players keep moving between network updates.
- **Darts.** Both players can see the throwing hand and dart. The guest gets immediate feedback on a button press. The host checks the guest's aim against the closest aiming position it previously sent.
- **Gopher Golf, Chicken Launch and Whack-a-Rac.** In Gopher Golf, spectators can see the gopher surface and follow its trail of disturbed earth. In Chicken Launch, the spectator camera follows the bird in flight. In Whack-a-Rac, the targets keep moving between network updates.
- **Barnyard Pool.** The balls and cue keep moving between network updates. The guest's power meter starts when they press the button and stops when they release it.
- **Cow Tipping.** Projectiles move on screen between physics updates.

We played all 14 LAN minigames using two Windows game instances. In Darts, with 400 ms of simulated round-trip latency, the host recorded all 60 horizontal and vertical aim selections exactly as the guest saw them on the first button press. In Barnyard Pool, both players saw the same result with the host at 30 FPS and the guest at 120 FPS, and again with the frame rates reversed.

In Gopher Golf, we checked the end of the host's first turn, the handoff to the guest and the spectator view on both sides. The test ended during the guest's turn. A playthrough on separate SteamOS and Windows devices is still pending.
