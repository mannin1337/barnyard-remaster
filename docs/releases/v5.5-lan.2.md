# Barnyard Remaster v5.5-lan.2 – LAN bike race remount fix

After a fall in a LAN bike race, the wheels can now touch the ground again when you get back on, so you can keep riding. In a test with two Windows game instances, the host and guest remounted 16 times between them using the regular controls. Both continued riding after their final fall.

This release includes the earlier LAN fixes. In Darts, both players see the throwing hand and the guest can lock their aim with a button press. In Barnyard Pool, the guest's power meter responds locally. Mud Jumpers loads the arena when playing as a female character. Gopher Golf spectators can see the gopher and its trail of disturbed earth. [Full notes for v5.5-lan.1](https://github.com/mannin1337/barnyard-remaster/releases/tag/v5.5-lan.1)

**Windows and Linux (including SteamOS) use the same download, `Barnyard_Remaster_v5.5_PC_Patch.zip`.** Each player needs their own installation of the original two-disc Barnyard PC game. The installer builds the remaster in a separate folder. To bring over saves from an earlier v5.5 installation, use `--previous` and `--copy-saves` together. On Windows, the host runs `Barnyard_LAN_szerver.bat` and the guest runs `Barnyard_LAN_csatlakozas.bat`. Select **LAN Minigames** from the pause menu on the farm. [Windows and Linux (Proton) setup guide](https://github.com/mannin1337/barnyard-remaster/blob/main/RemasterTools/Patch/INSTALL.md)
