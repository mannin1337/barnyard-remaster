# Barnyard Remaster v5.5-lan.3 – Co-op setup in English

[**Download the patch for Windows and Linux**](https://github.com/mannin1337/barnyard-remaster/releases/download/v5.5-lan.3/Barnyard_Remaster_v5.5_PC_Patch.zip) · [Installation and save transfer](https://github.com/mannin1337/barnyard-remaster/blob/v5.5-lan.3/RemasterTools/Patch/INSTALL.md)

This release makes it easier to start a two-player session. Install the patch using your own copy of the original two-disc Barnyard PC game. This download runs directly on Windows and through Proton on Linux, including SteamOS.

- **On one PC**, connect a controller for player two, then choose **Co-op → Same Screen** from the main menu.
- **On two computers**, choose **Co-op → Host LAN Game** on one and **Co-op → Join LAN Game** on the other. Windows players can also launch directly with `Host_LAN.bat` or `Join_LAN.bat`. Use `Play_Barnyard.bat` for the regular menu.
- **For a minigame**, open **LAN Minigames** in the pause menu on the farm and invite your partner. You can play Mud Jumpers at the same time, trade throws at the same dartboard, or watch each other's turns in Gopher Golf.

[View the current co-op gallery](https://github.com/mannin1337/barnyard-remaster#play-together)

**Already on v5.5-lan.2?** You can keep playing your existing installation with the same saves. This release ships the identical game executable and 235 shaders with an English installation guide and Windows launcher names. Fresh profiles start in English (UK). Existing language preferences carry over, and Hungarian remains available in **Options → Language**.
